# RFID

A modern Flutter application for RFID tag scanning and management.

## Features

- RFID tag scanning
- Inventory management
- Item tracking
- Clean Architecture
- BLoC State Management
- Material 3 UI

## Tech Stack

- Flutter
- Dart
- BLoC
- GetIt
- Dio

## Getting Started

```bash
flutter pub get
flutter run
```

## Requirements

- Flutter SDK
- Android Studio
- Android device with RFID support
